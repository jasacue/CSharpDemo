# Overview

C# is an easy to install and easy to use programming language. It is a compiled language and runs very quickly when it is programmed well. 

My software works by being run from the command line and printing the words "Hello World" to the console. 

The purpose of this software was to review using git, and to begin a personal software portfolio. 

[Software Demo Video](https://www.youtube.com/watch?v=7hPgFWZOgsY)

# Development Environment

This project was developed using the IDE Visual Studio Code. 

I used C# to program this hello world program, the .NET developer platform, and the standard C# library as well, all of which are developed and maintained by Microsoft.
